IN2140 Quiz (Lecture 09)

Part A — Theory (70%)

1) Multiple Choice: Which is a main motivation for IPv6?
A) Smaller headers than IPv4
B) More addresses and better scalability
C) Removal of routing
D) No need for DNS
Answer: B
2) True/False: IPv6 was designed partly to improve support for mobility and QoS.
Answer: True
3) Multiple Choice: In CIDR routing, if multiple entries match, routers choose:
A) First inserted rule
B) Shortest mask
C) Longest matching prefix
D) Random rule
Answer: C
4) Match: 1.Netmask 2.Subnet address 3.Host/interface part 4.Longest prefix match
a. Chooses most specific route b. Identifies network bits c. Device-specific part d. Result of address & mask
Answer: 1-b, 2-d, 3-c, 4-a
5) Multiple Choice: Which field exists in IPv6 header (but not as same purpose in IPv4)?
A) Header checksum
B) Flow label
C) Fragment offset (mandatory)
D) IHL
Answer: B
6) True/False: IPv6 routers fragment packets in-network just like IPv4 routers.
Answer: False
7) Multiple Choice: Valid compressed IPv6 notation example:
A) 2a00::1450::80a::2004
B) 2a00:1450:400f:80a::2004
C) 2a00-1450-400f-80a-2004
D) 2a00:1450:400f:80a:0:0:0:0:2004
Answer: B
8) Multiple Choice: A link-local IPv6 address typically starts with:
A) 2001::
B) FE80::
C) FF00::
D) FC00::
Answer: B
9) True/False: Before using a self-assigned IPv6 link-local address, duplicate-address checking is performed.
Answer: True
10) Multiple Choice: Transport layer multiplexing/demultiplexing is mainly based on:
A) MAC addresses
B) IP TTL
C) Port numbers + endpoint info
D) Ethernet type only
Answer: C
11) Match service to default port: 1.SSH 2.SMTP 3.DNS 4.HTTP — a.53 b.25 c.22 d.80
Answer: 1-c, 2-b, 3-a, 4-d
12) True/False: A TCP socket pair can be described by endpoint address+port on both sides.
Answer: True
13) Multiple Choice: DNS is best described as:
A) Flat namespace managed by one server
B) Hierarchical distributed naming system
C) Broadcast-only naming protocol
D) Link-layer addressing scheme
Answer: B
14) Multiple Choice: Root DNS servers are primarily responsible for:
A) Storing every hostname globally
B) Hosting only local university zones
C) Referring queries toward TLD authorities
D) Replacing recursive resolvers
Answer: C
15) True/False: DNS caching lowers latency and server load, but can delay visibility of updates.
Answer: True
16) Multiple Choice: Recursive DNS query behavior:
A) Resolver does all follow-up steps for client
B) Every reply is always authoritative
C) No server keeps any state
D) Cannot use cache
Answer: A
17) Match DNS record to use: 1.A/AAAA 2.NS 3.SOA 4.SRV — a.Service location b.Zone authority metadata c.Name server delegation d.Hostname to IP
Answer: 1-d, 2-c, 3-b, 4-a

Part B — Programming-style (30%)

18) Multiple Choice: socket(AF_INET, SOCK_DGRAM, 0) creates:
A) IPv6 TCP socket
B) IPv4 UDP socket
C) Raw Ethernet socket
D) Unix domain stream socket
Answer: B
19) True/False: UDP communication can work without calling listen()/accept().
Answer: True
20) Multiple Choice: In C socket setup for IPv4 bind, addr.sin_family should be:
A) PF_PACKET
B) AF_INET
C) AF_UNIX
D) IPPROTO_TCP
Answer: B
21) Multiple Choice: A client opening many simultaneous TCP connections to one server mostly varies its:
A) Destination IP
B) Destination port
C) Source ephemeral port
D) DNS zone
Answer: C
22) True/False: In transport demultiplexing, destination port helps deliver incoming data to correct process.
Answer: True
23) Order (iterative DNS): A.Local resolver asks root B.Resolver asks TLD C.Resolver asks authoritative D.Resolver returns final answer
Answer: A → B → C → D
24) Multiple Choice: If dst_addr & netmask == subnet_addr, destination is:
A) Unknown
B) Local subnet match
C) Always external route
D) Loopback-only
Answer: B
